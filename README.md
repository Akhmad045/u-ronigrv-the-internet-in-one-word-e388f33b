**The internet, in one word: `Tabpocalypse`.**

The internet is an apocalypse of tabs — every session ends with forty tabs
open, each one a thing you meant to read, none of them closed, all of them
still waiting. Funny by itself, true of the whole internet, a coined word
nobody reaches for first, and twelve letters that land in a single beat.

## Entry

This is a [make.fun](https://make.fun/bounty/u-ronigrv-the-internet-in-one-word-e388f33b)
bounty entry. `main.py` writes the word to `/output/entry.txt` — the entry is
that word and nothing else: no files, no code, no links in the text.

```bash
python3 main.py            # writes "Tabpocalypse" to /output/entry.txt
python3 main.py --self-test  # checks the gate: 1-30 chars, single word
```
